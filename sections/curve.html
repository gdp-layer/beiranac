北燃第二曲线的详细拆解

战略方向
方向一：以天然气为主业，同时向氢、电、热等综合能源领域发展
• 主动切入"热泵"全价值链运营（生产 - 安装 - 售后），推动终端全面电气化
• 持续推广"冷热电三联供"项目，构建综合能源调控能力，发展能源托管服务
• 通过锅炉房托管、智能温控终端推广，提升城市集中供暖的精细化调度，消除供暖末端的系统性浪费
方向二：紧扣城市更新行动，通过"智慧管网 + 终端改造"双驱动，打造首都城市的安全底座
• 推动"感知神经"向管网末端延伸，构建基于边缘计算的风险秒级自动预判与闭环阻断机制
• 加快老旧小区户内终端"智能化替代"，通过非侵入式监测实现"隐形泄漏"的精准捕捉与预防
• 依托安全感知底座，推动安全服务从"低频维保"向"高频价值链接"转变，释放商业溢价
方向三：发挥百万用户数据价值，为首都数字城市提供底层数据支撑
• 构建"适老化安全守护"模型，利用非侵入式的用气监测与预警，为独居老人提供主动式民生关怀服务
• 跨界联动公安、住建、食安等部门，为非法群租排查、风险源定位等城市治理难点提供"风险雷达"支撑
• 动态监测"能源碳足迹"，将用户用气行为转化为可量化的绿色资产，赋能生态安全与绿色金融
综合能源能力底座
定位
打造适配首都都市圈发展的综合能源供给体系，为从"单一燃气供应商"向"综合服务商"转型筑牢坚实能源底座，同时助力首都"双碳"目标与新质生产力培育落地。
主流运营模式
1
重资产投资型
BOT/BOO/BOOT：服务商全额投资拥有资产，建设-运营-移交（到期），适合大型园区 / 商业综合体 / 数据中心 / 文旅项目
TOT：存量盘活，运营已建好的资产，到期返还
2
工程 + 运维型
EPC：单纯工程总包
OM：纯运维托管
EPC + OM：业主投资、业主资产，服务商只做设计 - 采购 - 施工 + 长期运维，收建设费 + 运维费。适合政府、国企；业主坚持自有资产、不愿出让运营权
3
效益/服务型
EMC 合同能源管理：服务商投资改造节能，与业主按比例分享节能收益
EaaS 能源即服务：订阅制、按需付费，资产永久归服务商或专业资产公司，客户彻底实现
当前布局
以 BOT/BOO 为主、EaaS 为辅
BOT: 北京环球影城 CCHP 能源中心：天然气 + 地热 + 光伏多能互补
BOO+ EaaS: 城市副中心天然气耦合地源热泵分布式能源项目
BOO+ EaaS: 中石油创新基地数据中心三联供
建议运营模式
综合能源项目以低风险的 EPC+OM 为基础，再逐步推进高收益、高风险的 EMC/EaaS，针对 BOT/BOO 项目严格控制，未来可以逐步走能源托管模式
全用户价值服务体系
定位
以承接首都都市圈民生保障、服务城市高质量发展为核心，打破传统燃气服务边界，构建"安全保障 + 能效提升 + 场景延伸 + 增值赋能"等的生态协同用户服务价值体系
